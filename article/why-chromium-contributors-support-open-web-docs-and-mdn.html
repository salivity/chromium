Why Chromium Contributors Support Open Web Docs and MDN

Contributors from the Chromium web browser project support the Open Web Docs collective to ensure the long-term survival, accuracy, and vendor neutrality of MDN Web Docs. Following significant corporate restructuring at Mozilla in 2020, the future of MDN's core technical writing team became uncertain. Recognizing MDN as the definitive resource for web developers worldwide, major Chromium backers—including Google, Microsoft, and Igalia—stepped in to help establish, fund, and govern Open Web Docs. This strategic backing guarantees that evolving web standards are consistently documented, prevents the fragmentation of developer resources, and sustains a healthy, open web ecosystem.

Protecting the Single Source of Truth

Years before the creation of Open Web Docs, major browser vendors made a conscious decision to abandon their proprietary documentation platforms in favor of MDN. Microsoft redirected its MSDN web documentation to MDN, and Google migrated much of its Web Fundamentals content to the platform.

By the time Mozilla reduced its MDN staff in 2020, Chromium contributors had already invested heavily in making MDN the single source of truth for web developers. Supporting Open Web Docs was a necessary move to protect that investment. Without an independent organization employing full-time technical writers, MDN risked falling into disrepair, which would have forced Chromium contributors to rebuild their own separate documentation platforms from scratch.

Keeping Pace with Browser Innovation

The Chromium project introduces new web APIs, CSS features, and JavaScript capabilities at a rapid pace. However, a new browser feature is only useful if web developers know it exists and understand how to implement it.

Chromium engineers rely on the professional technical writers at Open Web Docs to translate complex engineering specifications into clear, accessible guides and reference materials. By funding Open Web Docs, Chromium contributors ensure there is a dedicated workforce available to document new web capabilities as soon as they are shipped in browsers.

Maintaining Vendor Neutrality

Although Chromium powers the majority of modern web browsers, the health of the internet relies on open standards and cross-browser compatibility. If Google or Microsoft were to directly take over web documentation, developers might view the content as biased toward Chromium-based browsers at the expense of Firefox (Gecko) and Safari (WebKit).

Open Web Docs operates as an independent collective. By channeling financial support and engineering expertise through this neutral third party, Chromium contributors help maintain trust within the developer community. Open Web Docs writers document how features work across all browsers, highlighting compatibility issues objectively rather than promoting a single browser engine.

Shared Financial Responsibility

Maintaining thousands of pages of technical documentation requires continuous effort, including updating outdated code samples, removing deprecated APIs, and reviewing community pull requests. Prior to Open Web Docs, Mozilla bore the brunt of this financial burden alone.

The creation of Open Web Docs allowed Chromium contributors to share the cost of maintaining the web's critical infrastructure. By pooling funds and resources into a single collective, organizations like Google, Microsoft, Samsung, and Igalia can efficiently sustain a team of full-time writers at a fraction of the cost of running independent documentation teams.
